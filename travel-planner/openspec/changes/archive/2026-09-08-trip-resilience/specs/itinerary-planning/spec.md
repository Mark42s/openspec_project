# itinerary-planning spec delta

## ADDED Requirements

### Requirement: 计划说明包含出行韧性提示
系统 SHALL 在最终行程说明（note）末尾按需追加确定性生成的韧性提示，规则如下，不写入模型提示词：用户晕车且行程含长途地面交通段（计划或候选中出现"包车/拼车/大巴/班车"类内容）时，追加长途乘车提醒；用户声明轻装时，在存在景区/换乘日的当天说明中提示寄存与减负；用户体力档为 intensive 且行程超过 4 天时，追加"建议安排恢复窗口"提示。任何规则均不得篡改模型已生成的行程正文。

#### Scenario: 晕车且行程含长途地面交通
- **WHEN** 请求 `motion_sickness=true`，且计划或检索候选中出现"拼车/包车"类内容
- **THEN** note 末尾追加乘车提醒（如坐前部、备药、勿低头看手机），正文行程不受影响

#### Scenario: 轻装用户
- **WHEN** 请求 `pack_light=true` 且计划含跨住宿点迁移日
- **THEN** 相关日说明出现寄存/减负提示

#### Scenario: 无约束时不追加
- **WHEN** 请求无任何场景字段
- **THEN** note 与无此功能时完全一致
