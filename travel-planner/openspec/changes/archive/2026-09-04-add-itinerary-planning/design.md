## Context

在既有 travel-planner MVP 上做增量(复用见本仓库归档 change)。现状:`POST /api/plan` 已能做 意图解析→交通/酒店并发检索(mock)→快照→结构化建议。本变更补齐"景点、逐日路线、费用、实时资讯、网页"。沿用受控 workflow:模型只做解析与规划编排,检索/交叉/费用皆确定性代码。动机与边界见 proposal.md。

## Goals / Non-Goals

**Goals:**
- 多平台(高德/腾讯/百度)POI 交叉,≥2 平台命中即标可信,单源保留但标注。
- 输出 day-by-day(偏好/天数/预算驱动)+ 确定性费用分解,演示模式(无 key)也能端到端跑。
- 极简单文件网页;实时资讯默认关、开则标记。
- 全程 OpenSpec change(propose→apply→archive)。

**Non-Goals:** 多城市串联路线、真实交通/酒店接入、下单/退改、跨平台价格一致性、价格预测。

## Decisions

**D1. 交叉验证按"名称归一化 + 坐标近似",不搞模糊实体链接。**
归一化 = 去空白/去掉景区/公园/公园/博物馆等可容忍后缀;同城两平台坐标距离 < ~1km 且归一化名命中即计一次命中。≥2 命中 → verified。**为何**:demo 追求可解释与低误报;轻规则足够,复杂实体对齐属于未来。**权衡**:平台命名差异大时可能漏判 → 单源结果仍保留降级。

**D2. 景点关键词由偏好映射生成(规则表),而非让模型自由发挥。**
人文→`博物馆,古迹,历史`;美食→`小吃街,美食`;自然→`公园,山水,景区`;亲子→`游乐园,海洋馆,动物园`;无偏好→`景点,名胜`。**为何**:确定性、免去一次模型调用;搜索结果可复现。

**D3. 费用计算用规则常量,不经模型。**
`transport=最低往返交通×2`,`hotels=选中酒店×晚数`,`tickets=行程内各景点门票之和`,`meals=天数×人数×餐饮档(默认 80/人/日,可配置)`,`per_person=total/出行人数`。**为何**:模型心算不可靠且费 token;费用是数值约束。mock 门票使用知名景点常见价(演示)。

**D4. 逐日规划 = 模型编排(有 key)或确定性轮转(无 key)。**
模型版:把偏好约束 + 天 + top-N 景点 + 交通/酒店给主模型输出 ItineraryDay[]。演示版:首日"到达+近处 1-2 点"、末日"返程宽松"、中间按景点分天,附休息时段;老人偏好 → 每日上限 2 点并加"午休"。**为何**:保真与零配置两者都要。**权衡**:模型版结果质量随偏好提示质量波动——提示里显式写"每日 2-3 点、留返程日"等软约束。

**D5. 实时资讯用"单次有界手动循环"调用 server tool `web_search_20260209`。**
有 key 且 `WEB_RESEARCH_ENABLED=1` 才执行;最多 3 次工具调用后退出,处理 `pause_turn` 重试上限;产出压缩文本拼进规划 prompt 并标 `web_research_used`。**为何**:默认不花钱,开则给真实最新资讯。**权衡**:web 结果质量参差 + token 增加 → 有界+默认关。

**D6. 网页为无构建单文件,直接 `FileResponse`/挂载静态。**
FastAPI 已有;单个 `app/web/index.html` fetch `/api/plan` 渲染。**为何**:零构建、零新增前端依赖,最省事可演示。

## Risks / Trade-offs

- **平台 key 缺失**:→ 回落 mock 真实知名景点并标 `is_mock`;交叉真实性需至少配 1-2 个 key。
- **平台配额/字段漂移**:→ 每 provider 独立 try/except,失败即剔除该源,交叉自动降级为"可用源计数"。
- **网页搜索结果时效/准确性无保证**:→ `web_research_used` 标记 + UI 注明"以现场/官网为准"。
- **费用为估算**:mock 票价非实时报价 → UI/README 明示为估算,不作为结算依据。
- **OpenSpec spec 语法严格**(场景须 4 个 `#`):→ 写完 `openspec validate` 把关。

## Migration Plan

绿地增量,无迁移。落地顺序:models 扩展 → poi.py → costing.py → llm.py(逐日+live)→ main.py+网页 → tests。验证链:pytest → ruff → uvicorn + curl(`/api/plan`、`/`)→ `openspec archive`。
